# Mealy–Moore Machine Transformation Studio — Project Report

## Abstract
This project implements a desktop-first interactive tool for defining deterministic Mealy machines, constructing equivalent Moore machines, explaining the construction, simulating words, and checking the transition correspondence. It uses explicit state splitting and documents the Moore initial-output alignment convention.

## Introduction and problem statement
Mealy machines place output labels on transitions, while Moore machines place them on states. The project addresses the conversion and its common off-by-one output issue through an explicit initial Moore state and a traceable construction.

## Objectives and scope
Users can edit and validate a complete deterministic Mealy table, convert it, view both diagrams, simulate words, inspect verification checks, and export JSON, CSV, SVG, and Markdown trace data. Conversion is implemented locally and does not depend on a machine-conversion library.

## Requirements
Python 3.11 or newer is recommended, with Streamlit, pandas, Graphviz's Python package, and pytest. A modern desktop browser is needed. The diagrams use Streamlit's Graphviz renderer; standalone SVG export is generated by the project. PNG export is not included because renderer availability varies by installation.

## Mealy and Moore theory
A Mealy machine is `M=(Q,Σ,Γ,δ,λ,q₀)` with output per transition. A Moore machine is `M′=(Q′,Σ,Γ,δ′,λ′,q′₀)` with output per state. See [theory.md](theory.md) for the formal definitions and output convention.

## Mathematical conversion algorithm
For each destination `p`, collect all outputs on transitions entering `p`. Create `(p,o)` for every observed output `o`. Add a separate start state with sentinel output `ε (initial)`. From the start, on input `a`, transition to `(δ(q₀,a), λ(q₀,a))`; from `(q, previous)`, on `a`, transition to `(δ(q,a), λ(q,a))`. Optionally remove states unreachable from the start. Full pseudocode and correctness argument are in [algorithm.md](algorithm.md).

## System architecture
`core/models.py` holds immutable machine records; `validator.py`, `converter.py`, `simulator.py`, `verifier.py`, and `io.py` provide the mathematical operations and serialization. `visualization/` renders DOT and SVG. `app.py` provides the Streamlit navigation and workflows.

## Flowchart
```text
Define Mealy machine → Validate completeness → Collect incoming outputs
        → Create variants and initial sentinel → Generate transitions
        → Reachability prune → Simulate and verify → Export
```

## Implementation details and sample
The four bundled examples include binary parity, a destination requiring a split, self-loops, and three output symbols. In the split example, `t` receives both `x` and `y`, so Moore states `t / x` and `t / y` are created. For any input word, Moore's first output is the sentinel; the subsequent outputs match the Mealy output word.

## Testing methodology and results
Pytest cases cover conversion of all examples, state splitting, single-state loops, unreachable states, input/output alignment, invalid transitions, and JSON round trips. Run `python -m pytest -q`. Report the local test command's actual result during demonstration; no performance benchmark is claimed.

## Complexity
With `|Q|` Mealy states, `|Σ|` inputs, and `|Q′|` generated Moore states, the complete construction and reachability traversal take `O(|Q||Σ| + |Q′||Σ|)` time and `O(|Q′||Σ|)` transition storage.

## Limitations
The builder accepts comma-separated symbol names, and simulator words use concatenated characters for single-character alphabets or whitespace-delimited tokens when multi-character symbols are present. State layouts are deterministic circular layouts; SVG is provided, while PNG export is not. The checker verifies the construction over all reachable state/input correspondences and also performs a supplementary bounded word check.

## Future scope
Possible extensions include interactive node dragging, additional machine formats, configurable initial output conventions, minimized Moore machines, and PNG rendering when a system Graphviz executable is installed.

## Conclusion
The application makes the standard incoming-output state-splitting construction inspectable and testable, while making the Moore initial-output alignment explicit in simulation and verification.
